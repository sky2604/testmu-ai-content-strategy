# Winning Commercial Search

Interactive strategy experience for the TestMu AI Senior Content Strategist assignment.

Prepared by Akash Sinha (Sky), September 2026. Target page: [testmuai.com/visual-testing-tool/](https://www.testmuai.com/visual-testing-tool/).

Repository: [github.com/sky2604/testmu-ai-content-strategy](https://github.com/sky2604/testmu-ai-content-strategy)

## What this is

A cinematic, multi-route case study that turns the written SEO + GEO + AEO brief into a hiring-manager journey:

Brief, Audit, SERP, Competitors, Keywords, Content, GEO/AEO, Conversion, Redesign, 90 Days, Measurement, Close.

The assignment is the source of truth. Live research is labeled separately. Directional estimates are labeled as such. Search volumes, rankings, traffic, and conversion rates are not invented.

## Stack

React 19, TanStack Start, Tailwind v4, lucide-react. Geist + Silkscreen.

## Local

```bash
npm install
npm run dev
```

The app binds to port 8080.

## SEO on this site

- Unique titles and meta descriptions per route
- Semantic heading hierarchy
- Canonical links
- robots.txt and sitemap.xml
- FAQ-style answer blocks and Article JSON-LD
- Accessible navigation, skip link, keyboard-usable menus

## Integrity

Findings, recommendations, keywords, competitor notes, hero rewrite, 90-day plan, and GSC KPIs map to the original assignment. Live checks of TestMu, Applitools, Percy, and Chromatic are dated September 2026 and marked Live research.
